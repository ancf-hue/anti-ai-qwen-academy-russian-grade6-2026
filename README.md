Анти-ИИ Квен Академия — Русский язык • 6 класс • PRO • 2026 — бесплатный одностраничный HTML-тренажёр для подготовки иностранных граждан к тестированию по русскому языку при поступлении в 6 класс. Построен по образцу демо-вариантов ФИПИ 2026.

Полностью работает офлайн — без сервера, регистрации, базы данных и рекламы. Достаточно открыть index.html в любом современном браузере.

🎯 Назначение
Подготовка к диагностическому тестированию, определяющему готовность ребёнка к обучению в 6 классе на русском языке. Полная база из 4 вариантов (A–D), по 14 заданий в каждом.

📋 Структура теста (один вариант)
Устная часть (15 минут, 10 баллов):

№	Задание	Макс. балл
1	Диалог (помощь дома / книги / лето / питомцы)	1
2	Монолог по фото (5+ предложений)	2
3	Чтение вслух	3
4	Пересказ по плану	4
Письменная часть (45 минут, 12 баллов):

№	Задание	Макс. балл
5–8	Слушание (по 1 баллу)	4
9–12	Грамматика и лексика (по 1 баллу)	4
13	Списывание с пропущенными буквами	2
14	Сочинение (70+ слов)	2
Итого: 22 балла. Проходной — 20 (из них не менее 9 за устную часть).

✨ Возможности
🌐 Три языка интерфейса — русский, узбекский, английский (переключение по клику на RU/UZ/EN)

🌙 Тёмная / светлая тема

📚 4 варианта (A–D) — переключение кнопками в верхней панели

🎓 3 режима работы — Тренировка / Экзамен / Работа над ошибками

⏱️ Два таймера — письменная (45 мин) и устная (15 мин)

✅ Автопроверка заданий 5–12

📝 Самооценка устной части по критериям ФИПИ (с учётом разного максимума)

🔤 Счётчик слов в задании 14 — минимум 70 слов для зачёта

🔍 Фильтры — слушание / грамматика / письмо

📊 Статистика — по разделам, вариантам, точность

💾 Экспорт результатов в .txt одной кнопкой

🖨️ Печать — специальный @media print для распечатки варианта

💡 Показать ответ — эталон для устной части и заданий 13–14

📱 Адаптивный дизайн — телефон, планшет, ПК
